# GAN-based image-to-image translation and synthetic-data generation

Use generative adversarial networks to transform image appearance or create
synthetic images for model development and augmentation.

## Projects showing this skill

- [GAN Hormiga: Road-Image Generation and Enhancement](../projects/gan-hormiga-road-image-generation-and-enhancement.md) — the deck presents GAN-generated images and CycleGAN-style road-texture transfer; images were not visually inspected ([generation](../sources/gan-hormiga-20210820-gan-hormiga-v1-pptx.md#slide-3); [transfer](../sources/gan-hormiga-20210820-gan-hormiga-v1-pptx.md#slide-4)).
- [GAN Publication: Advanced GAN for Tire-Defect Augmentation](../projects/gan-publication-advanced-gan-for-tire-defect-augmentation.md) — the paper describes GAN-generated tire-joint images augmenting limited, imbalanced datasets ([augmentation experiments](../sources/gan-publication-gan-paper-formatted-2-pdf.md#classification-augmentation-results)).
- [GAN API Hackathon: Image Preprocessing Service](../projects/gan-api-hackathon-image-preprocessing-service.md) — the deck lists EnlightenGAN, Blur2Sharp, style/domain transfer, and GAN-based image generation for augmentation ([slides 4–5](../sources/gan-api-hackathon-20211116-api-hackathon-v002-pptx.md#slide-4)).
- [GAN Exploration, Image Synthesis, and Data Augmentation](../projects/gan-exploration-image-synthesis-and-augmentation.md) — the sources describe synthetic image generation for surface defects and tire data, including augmentation proposals for limited data ([V5 applications](../sources/gan-exploration-20200717-gan-study-v5-pptx.md#slide-4); [overview PDF](../sources/gan-exploration-20200925-gan-overview-pdf.md#page-4); [2020 study](../sources/gan-exploration-20200717-gan-study-v3-pptx.md#slide-2); [tire-health](../sources/gan-exploration-ai-moonshot-gan-09122021-pptx.md#slide-4)).
- [GAN KAR Hackathon: Tire-Joint Defect Augmentation](../projects/gan-kar-tire-joint-defect-augmentation.md) — the presentation describes generated defect images as augmentation for imbalanced tire-joint classes ([slide 19](../sources/gan-kar-20210310-gan-hackathon-kar-v1-pptx.md#slide-19)).
- [GAN for OCR Text-Image Generation and Preprocessing](../projects/gan-ocr-text-image-generation-and-preprocessing.md) — the deck labels GAN text-image generation and domain adaptation for OCR patches ([slides 5](../sources/gan-ocr-20210505-gan-ocr-v1-pptx.md#slide-5), [7](../sources/gan-ocr-20210505-gan-ocr-v1-pptx.md#slide-7)).

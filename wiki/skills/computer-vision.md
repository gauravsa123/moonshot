## Projects showing this skill

- [GAN Hormiga: Road-Image Generation and Enhancement](../projects/gan-hormiga-road-image-generation-and-enhancement.md) — the deck describes image generation, road-texture transfer, and enhancement, but does not identify an ultimate computer-vision task ([overview](../sources/gan-hormiga-20210820-gan-hormiga-v1-pptx.md#slide-2); [texture transfer](../sources/gan-hormiga-20210820-gan-hormiga-v1-pptx.md#slide-4)).
- [GAN Publication: Advanced GAN for Tire-Defect Augmentation](../projects/gan-publication-advanced-gan-for-tire-defect-augmentation.md) — the paper describes tire-joint image classification and GAN-based image augmentation; results and figures have not been independently reviewed ([classification results](../sources/gan-publication-gan-paper-formatted-2-pdf.md#classification-augmentation-results)).
- [DDI DroneCV Traffic and Road-Safety Analytics](../projects/ddi-dronecv-traffic-and-road-safety-analytics.md) — the deck describes processing drone/CCTV video to detect and track vehicles and derive visual measurements ([slides 3](../sources/ddi-dronecv-20230131-dronecv-v2-pptx.md#slide-3), [7](../sources/ddi-dronecv-20230131-dronecv-v2-pptx.md#slide-7)).
- [GAN Exploration, Image Synthesis, and Data Augmentation](../projects/gan-exploration-image-synthesis-and-augmentation.md) — the sources describe defect-image synthesis and a downstream tire-conicity object-detection experiment; result visuals and metrics remain unreviewed ([surface defects](../sources/gan-exploration-20200717-gan-study-v3-pptx.md#slide-2); [object detection](../sources/gan-exploration-20200717-gan-study-v3-pptx.md#slide-50)).
- [GAN for IRIS2 Multimodal Tire Imaging](../projects/gan-iris2-multimodal-tire-imaging.md) — the presentation identifies six IRIS2 tire-image modalities and generated outputs for those image types ([slide 8](../sources/gan-iris2-20210401-gan-iris2-v1-pptx.md#slide-8); [modality outputs](../sources/gan-iris2-20210401-gan-iris2-v1-pptx.md#slide-26)).
- [GAN KAR Hackathon: Tire-Joint Defect Augmentation](../projects/gan-kar-tire-joint-defect-augmentation.md) — the presentation targets tire-defect object detection and describes generating examples for its defect classes ([slide 19](../sources/gan-kar-20210310-gan-hackathon-kar-v1-pptx.md#slide-19)).
- [GAN for OCR Text-Image Generation and Preprocessing](../projects/gan-ocr-text-image-generation-and-preprocessing.md) — the deck describes generated text images and enhancement preprocessing for character recognition; it reports no downstream OCR metrics ([slide 10](../sources/gan-ocr-20210505-gan-ocr-v1-pptx.md#slide-10)).

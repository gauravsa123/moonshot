# PCA-based visualization of image-augmentation effects

Use PCA projections of image features to visualize and communicate how
augmentation changes the distribution and separation of labeled image
classes.

## Projects needing this skill

- [GAN Publication: Advanced GAN for Tire-Defect Augmentation](../projects/gan-publication-advanced-gan-for-tire-defect-augmentation.md) — user-confirmed project requirement.
- [GAN KAR Hackathon: Tire-Joint Defect Augmentation](../projects/gan-kar-tire-joint-defect-augmentation.md) — user-confirmed project requirement.

## Projects with user-reported use

- [GAN KAR Hackathon: Tire-Joint Defect Augmentation](../projects/gan-kar-tire-joint-defect-augmentation.md) — the user reports using PCA distribution plots to explain how augmentation improved separation among image labels; the claim is not independently verified.

## Projects showing this skill

- [GAN Publication: Advanced GAN for Tire-Defect Augmentation](../projects/gan-publication-advanced-gan-for-tire-defect-augmentation.md) — the paper describes PCA plots of real-only and augmented image distributions and claims improved class distinction; figures have not been visually reviewed ([PCA analysis](../sources/gan-publication-gan-paper-formatted-2-pdf.md#pca-analysis)).
- [GAN KAR Hackathon: Tire-Joint Defect Augmentation](../projects/gan-kar-tire-joint-defect-augmentation.md) — the presentation describes PCA plots and reports improved distinction among image categories after augmentation; the plots and analysis have not been visually reviewed ([slide 43](../sources/gan-kar-20210310-gan-hackathon-kar-v1-pptx.md#slide-43); [slide 44](../sources/gan-kar-20210310-gan-hackathon-kar-v1-pptx.md#slide-44)).

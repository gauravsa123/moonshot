# Workflow Mentoring Skill Design

## Decision

Create a distinct canonical skill titled **Mentoring and guiding interns in
workflow design and implementation**. Keep it separate from the existing
**Mentoring a trainee** skill, whose current user-reported use is associated
with Point Cloud.

## Scope

- Add one skill page with the standard wiki frontmatter and project-use lists.
- Add the skill as a **user-reported** contribution/capability to Agentic RAG
  and Browser Use.
- Add reciprocal project links to the new skill's “Projects with user-reported
  use” section and related metadata.
- Index the skill page and record the change in `wiki/log.md`.

## Provenance and exclusions

The user classified this as a user-reported capability. It must not be added
to “Know-how needed” or “Skills shown by sources,” and no source evidence,
personal mastery beyond the user's report, outcomes, or implementation details
will be inferred. The existing “Mentoring a trainee” page remains unchanged.

## Validation

Check that both project profiles and the new skill page link to each other,
that the skill is indexed, that the required canonical skill sections exist,
and that Markdown links resolve. Do not modify files under `raw/`.

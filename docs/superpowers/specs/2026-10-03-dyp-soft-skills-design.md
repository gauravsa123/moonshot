# Dynamic Pricing Soft-Skill Requirements Design

## Decision

Add five user-confirmed project requirements to Dynamic Pricing and reuse the
existing canonical skill pages:

| User wording | Canonical skill |
|---|---|
| Team collaboration | Cross-functional team collaboration |
| Leading the team | Team leadership |
| Stakeholder management | Stakeholder management |
| Leadership communication | Leadership communication |
| Support in decision making | Decision support and facilitation |

## Scope

- Add all five entries to the DYP profile's “Know-how needed” table with
  `user-confirmed` status and user-attributed rationales.
- Add DYP to each canonical skill page's “Projects needing this skill” list
  and to the DYP profile's `related` links.
- Add the five canonical links to the Dynamic Pricing requirements section of
  `wiki/index.md` and record the update in `wiki/log.md`.

## Provenance and exclusions

These are project requirements, not claims of personal use or source evidence.
Do not add them to DYP's “User-reported contributions and outcomes” or “Skills
shown by sources,” and do not create duplicate skill pages or modify source
records. Keep the existing Value Mate associations intact. Do not modify
anything under `raw/`.

## Validation

Confirm the five requirement rows are `user-confirmed`, all reciprocal links
resolve, each canonical skill lists both Value Mate and DYP as projects needing
it, the index includes all five links, and the activity log records the
provenance and scope.
